# Student FitTrack

### A Student Workout Tracking Mobile Application

Student FitTrack is a mobile application developed using **Flutter and Dart** to help students record, monitor and manage their workout activities. The application uses **SQLite** for local data storage, allowing users to manage their workout records directly from their mobile devices.

## 1. Project Overview

Students often have busy schedules due to academic responsibilities and other daily activities. Student FitTrack provides a simple way for students to keep track of their physical activities and maintain a record of their workouts.

The application allows users to add, view, edit and delete workout records through a simple and user-friendly interface.

## 2. Features

- **Splash Screen:** Displays the application name and introduction when launching the app.
- **Add Workout:** Allows users to create new workout records.
- **Input Validation:** Ensures required information is entered correctly before saving.
- **Workout Categories:** Supports different workout categories such as Cardio, Strength Training, HIIT, Yoga, Pilates, Cycling, Walking and more.
- **View Workout Records:** Displays saved workout information.
- **Workout Details:** Allows users to view complete workout information.
- **Edit Workout:** Allows users to update existing workout records.
- **Delete Workout:** Allows users to delete records after confirmation.
- **SQLite Database:** Stores workout records locally on the device.
- **Pagination:** Displays workout records in groups of ten per page.
- **Refresh:** Reloads workout records from the database.
